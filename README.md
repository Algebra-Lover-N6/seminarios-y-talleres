# Seminarios y Talleres de Matemática

Sitio web estático para organizar notas, seminarios, talleres y grupos de estudio.

## Estructura

- `index.html`: portada y contenido principal.
- `assets/css/styles.css`: estilos.
- `assets/js/app.js`: selector ES/EN.
- `404.html`: página de error.
- `.nojekyll`: permite servir el sitio directamente con GitHub Pages.

El sitio no requiere compilación ni dependencias.
